# 🔴⚫ Snake Game (Red-Black Theme)

A **classic Snake Game** built in **Java Swing**, featuring **object-oriented programming (OOP)** principles and a **red-black theme** for a sleek look.  

---

## 🎮 Features  
✔️ **Smooth Gameplay** – Move the snake using arrow keys  
✔️ **Food Mechanics** – Grow the snake by eating food  
✔️ **Boundary Wrapping** – Snake reappears on the other side when crossing edges  
✔️ **Game Over Detection** – Ends if the snake collides with itself  
✔️ **Score & High Score Tracking**  
✔️ **Dark-Themed UI** – Red and black aesthetic  

---

## 🛠️ Tech Stack  
- **Java** (Swing, AWT)  
- **OOP Concepts** (Interfaces, Encapsulation)  
- **Event Handling & Timers**
